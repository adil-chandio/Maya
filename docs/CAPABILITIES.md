# 🎯 MAYA AI — Commands List

Bol ke ya type karke commands do. Parser **English + Hinglish + Hindi (Roman)** samajhta hai.

## 🎵 YouTube / Music
| Command | Action |
|---|---|
| `romantic songs sunao` | YouTube par song search + play |
| `play karo na` | Trending songs |
| `youtube pe gaana chalao` | YouTube kholta hai |
| `play lofi on youtube` | Lofi search |
| `search youtube for memes` | YouTube search |

## 🌐 Web / Search
| Command | Action |
|---|---|
| `open google.com` | Website kholta hai |
| `youtube pe jao` | YouTube kholta hai |
| `search for recipes` | Google search |
| `google latest news` | Google search |
| `dhundho best laptops` | Google search |

## 📞 Communication
| Command | Action |
|---|---|
| `call mom` | Dialer kholta hai (contact saved ho to number) |
| `dial 1234567890` | Dialer |
| `text John saying hi` | SMS app + text |
| `whatsapp message to Kumail ki hi` | WhatsApp web/API pre-filled |
| `whatsapp pe message karo` | WhatsApp |

## 📲 Apps
| Command | Action |
|---|---|

| `launch instagram` | Instagram (native launch) |
| `kholo whatsapp` | WhatsApp (native launch) |
| `open netflix` | Netflix (native launch) |

## 🔆 System Control (native APK)
| Command | Action |
|---|---|
| `volume to 80` | Volume 80% |
| `mute volume` / `volume to 0` | Mute |
| `set brightness to 50` | Brightness 50% (Write Settings) |
| `increase brightness` | +20% |
| `torch on` / `flash off karo` | Flashlight toggle |
| `wifi off` / `wifi chalu karo` | WiFi toggle (Android 10+ settings) |
| `bluetooth on` / `bluetooth band karo` | Bluetooth toggle (Android 13+ settings) |

## 🔋 Info
| Command | Action |
|---|---|

| `phone status` | Device info (model, Android version, permissions) |
| `device info` | Same |
